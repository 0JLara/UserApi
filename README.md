# User API Explorer

Aplicación desarrollada con React y TypeScript que consume una API REST y permite visualizar y filtrar usuarios en tiempo real.

## 🚀 Funcionalidades

- Consumo de API REST con Fetch
- Visualización de datos de usuarios
- Filtrado en tiempo real por nombre
- Implementación de debounce para optimizar búsquedas
- Manejo de estados de carga y errores

## 🛠️ Tecnologías

- React
- TypeScript
- Hooks (useState, useEffect)
- Fetch API
- CSS

## 🎯 Objetivo

Practicar consumo de APIs, manejo de estado en React y optimización de rendimiento en búsquedas.
